## 产品渲染

Chromecast Voice Remote 按用户提供的 IMG_5453 / IMG_5454 / IMG_5455 实拍建立 SceneKit 模型。包括白色胶囊轮廓、连续椭圆弧形背壳、随曲面弯曲的电池盖接缝、黑色语音键、方向环、品牌快捷键、电源／输入源键和侧边连续音量摇杆。导览支持旋转、正侧背视图、点击按键、功能连线及实际按键高亮。

## 一致的功能规则

应用当前模式对已连接遥控器统一生效，各型号保留独立的自定义绑定。

| 组合 | 功能 |
| --- | --- |
| 原生 | T1／小米放行系统原生按键与系统听写；Chromecast 使用兼容按键及语音转文字 |
| 媒体 | 播放暂停、上下曲、音量、静音、切换播放器；按当前播放器列表路由 |
| 主机切换 | 已绑定的切换主机动作；使用已有显示器与 KMFU 配置 |
| 三种模式通用 | 模式循环键；语音在原生模式输入文字，在媒体／主机模式执行指令 |

语音键不能与模式键或主机动作共用同一个物理输入，以免在多个组合中同时触发。原生模式释放应用拥有的全部按键隔离，包括语音、静音、音量和模式键；T1／小米的原生事件直接交给系统，模式键只被观察，不吞掉其原生动作。小米 F5 语音键需要与 macOS「键盘 → 听写」中的快捷键设置相符。媒体／主机模式继续使用已配置麦克风和指令流程。Chromecast 使用独立 ATVV 蓝牙语音通道；原生模式只向按下时获得焦点的可编辑文本框输入转写，不执行识别出的控制指令。焦点或光标变化后停止输入，保留转写供用户查看。

Chromecast 保留兼容预设和用户自定义，原生音频键交给系统，媒体模式仍按播放器列表路由。电源／信号源只有在实际收到蓝牙键值时才能学习；本机 Chromecast 已观察到两键蓝牙报文，其他硬件配置仍应分别验收。

对没有 HAL 静音接口的数字输出，Mac 原生静音键使用私有 CoreAudio 进程 tap、以实际输出设备为时钟源的私有聚合设备和运行中的 IO 回调提供全局静音。回调不读取、记录或发送音频样本，只将聚合设备自身的输出贡献置零。音频注册与启动移出界面线程，避免系统音频授权等待阻塞界面。只有处理回调实际运行后才显示成功，不能只凭 tap 配置宣称静音生效。取消静音、输出设备变化或正常退出时解除，并提供应用内取消入口及桌面反馈。该兼容需要 macOS 14.2 或更新版本和系统音频权限，实际静音效果仍需硬件听音验收。

启用「优先调整播放器音量」时，媒体静音直接选择该播放器应用包内的音频进程（包含独立音频 helper），不依赖名为「静音」的按钮。其他播放器不会加入目标。未启用时使用系统输出静音。三款遥控器的映射及界面按钮共用这个路由。

Windows 原生模式保留三款遥控器的 Windows 原生功能，包括 Google 遥控器；没有加入 macOS 专用的蓝牙日志补偿。电脑语音快捷键在原生模式输入当前文本框，在媒体／主机模式执行指令。媒体静音选择播放器主进程及其音频子进程，并将多个 WASAPI 会话统一设置到同一静音状态，设置后读回核对。

Google 在 Mac 的原生语音已于 2026-11-27 实测输入文本编辑。原生转文字统一使用系统键盘 Unicode 事件，移除仅凭 AXSelectedText 写入返回值就报告成功的路径；启用 Electron 官方提供的辅助功能接口来预热支持的控件树。Codex 自身窗口受电脑工具访问限制，最终输入结果由用户亲自确认通过。收音、转写和无法输入的原因通过不抢焦点的桌面浮窗反馈。

T1 与小米保留原有自定义绑定。本机 Chromecast 原来没有绑定，本轮通过应用界面启用了 8 项媒体／主机预设：主页循环模式、OK 播放暂停、左右切歌、音量与静音、主机模式返回键切主机。语音使用独立 ATVV 通道；切播放器等其他动作可继续学习。Chromecast 的兼容开关和语音通道连接在对应映射页提供。

## 桌面模式提示

Mac 使用不激活窗口的 NSPanel，Windows 使用 WS_EX_NOACTIVATE 工具浮窗。切换时显示原生／媒体／主机切换及媒体模式的当前播放器；约 2.4 秒自动隐藏。连续切换重置计时，避免旧提示关闭新提示。支持减少动态效果；浮窗不接收键鼠输入。

Mac 已通过界面操作切换三种模式，ModeHUD 日志均显示：

```
mode=host visible=true keyWindow=false focusUnchanged=true
mode=native visible=true keyWindow=false focusUnchanged=true
mode=media visible=true keyWindow=false focusUnchanged=true
dismissed visible=false
```
